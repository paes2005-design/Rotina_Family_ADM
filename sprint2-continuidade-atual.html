# TAREFAS — FONTE CONGELADA
- Agenda por participante; opção Todos cria tarefa coletiva.
- Nome, ícone, início, término, pontos, tolerância e status na área principal.
- Ordenação automática pelo horário de início; não existe campo manual Ordenar.
- Web em tabela; mobile em cartões.
- Edição web na própria linha; mobile dentro do cartão. Não usar modal.
- Botão `⋯` no web abre Detalhes logo abaixo da tarefa.
- Botão Detalhes no mobile abre os mesmos opcionais dentro do cartão.

- Bloqueio de sobreposição de horários para o mesmo participante em dias coincidentes.

# CONQUISTAS — CONGELADO
Conquistas não são cadastro livre de Recompensas. Regras fixas:
1. Dias com todas as tarefas dentro do horário.
2. Tarefas consecutivas com 100%.
3. Dias sem necessidade de justificativa.
4. Pontos atingidos.
5. Percentual dos pontos possíveis.

Campos condicionais:
- Dias no horário / sem justificativa: meta + consecutivos/acumulados.
- Tarefas 100%: meta de tarefas consecutivas.
- Pontos: alvo + Sem prazo/Com prazo; com prazo define duração e dias/semanas/meses.
- Percentual: alvo + Semana/Mês.

Recorrência:
- Única: 1 ciclo e encerra.
- Periódica: quantidade definida pelo ADM; sucesso ou falha consome ciclo.
- Contínua: sem limite.

Validação ADM:
- Meta atingida gera **Aguardando validação do ADM**.
- Não entrega automaticamente.
- Próximo ciclo só abre após validação quando houver ciclo válido.
- Sem ciclos válidos: desativa no ADM e some do participante.
- Sucesso na última tentativa mantém a pendência no ADM até validação.
